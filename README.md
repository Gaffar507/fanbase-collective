# Fanbase Collective - WordPress Integration Guide

## 1. HTML & JS
- Open `index.html`, copy the entire code, and paste it into your WordPress "Custom HTML" block or WPCode plugin.

## 2. CSS Stylesheet
- Copy the content of `style.css` and paste it into **Appearance > Customize > Additional CSS** or your page builder's CSS section.

## 3. Image Upload (Important)
- Upload the images from the `assets/images` folder to your **WordPress Media Library**.
- Replace the image `src` paths in the HTML with your WordPress Media Library URLs.
